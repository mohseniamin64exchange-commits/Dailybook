# گزارش آزمون ثبت همزمان

## دامنه

برای بررسی رفتار ثبت همزمان، پنج thread مستقل با `ThreadPoolExecutor` ایجاد شد. هر thread در context جداگانهٔ Flask و با session مستقل SQLAlchemy، یک رکورد `DailyEntry` ثبت می‌کند.

پایگاه داده SQLite در فایل موقت ساخته شد؛ بنابراین آزمون از SQLite در حافظه استفاده نمی‌کند. تنظیمات موجود برنامه برای timeout اتصال و WAL نیز در این اجرا فعال بود.

## نتیجه

آزمون `tests/test_concurrency.py::test_five_concurrent_entries_on_file_sqlite` با موفقیت اجرا شد.

- تعداد رکوردهای ثبت‌شده: ۵
- تعداد شناسه‌های یکتا: ۵
- مقادیر ثبت‌شده: `1, 2, 3, 4, 5`
- خطای قفل یا از دست‌رفتن رکورد مشاهده نشد.

این آزمون یک بررسی سبک برای پنج ثبت همزمان است و جایگزین آزمون فشار یا بررسی رفتار در بارهای بسیار بالاتر نیست.

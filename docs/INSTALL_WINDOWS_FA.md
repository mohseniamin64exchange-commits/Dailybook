# راهنمای نصب استاندارد DailyBook روی ویندوز

## نصب برای کاربر نهایی

۱. فایل `DailyBook-Setup-x64.exe` را اجرا کنید.

۲. پیام UAC ویندوز را تأیید و مراحل Setup را با گزینه‌های پیش‌فرض ادامه دهید.

۳. پس از پایان نصب، DailyBook را از Start Menu یا میانبر Desktop باز کنید.

همین. نصب‌کننده همه وابستگی‌ها، سرویس Windows، قانون فایروال و میانبرها را
خودکار آماده می‌کند. Python، PowerShell، اینترنت یا اجرای فایل BAT لازم نیست.

## مسیرهای استاندارد

- فایل‌های برنامه: `C:\Program Files\DailyBook`
- دیتابیس و تنظیمات: `C:\ProgramData\DailyBook`
- پشتیبان‌ها: `C:\ProgramData\DailyBook\backups`
- گزارش سرویس: `C:\ProgramData\DailyBook\logs`

جدا بودن داده‌ها از فایل‌های برنامه باعث می‌شود Upgrade یا Uninstall معمولی،
اطلاعات را ناخواسته حذف نکند.

## اجرا و دسترسی شبکه

سرویس DailyBook با روشن شدن ویندوز خودکار اجرا می‌شود. روی رایانه سرور، میانبر
DailyBook مرورگر را باز می‌کند. کاربران شبکه نیز آدرس زیر را باز می‌کنند:

```text
http://IP-SERVER:4000
```

نمونه: `http://192.168.1.20:4000`

برای پایداری آدرس، بهتر است در روتر برای رایانه سرور DHCP Reservation تنظیم شود.
برنامه فقط برای LAN طراحی شده و نباید مستقیم روی اینترنت منتشر شود.

## تغییر پورت

مدیر می‌تواند پورت را از صفحه «تنظیمات» تغییر دهد. نسخه نصب‌شده قانون فایروال را
به‌روزرسانی می‌کند و سرویس پس از چند ثانیه خودکار Restart می‌شود. سپس آدرس را با
پورت جدید باز کنید؛ برای نمونه `http://192.168.1.20:4789`.

## Upgrade و حذف

برای Upgrade، Setup نسخه جدید را روی نسخه قبلی اجرا کنید. سرویس متوقف و نسخه
جدید جایگزین می‌شود، ولی دیتابیس و بکاپ‌ها باقی می‌مانند.

DailyBook از Settings ویندوز یا Start Menu قابل Uninstall است. هنگام حذف، Setup
می‌پرسد آیا داده‌ها و بکاپ‌ها نیز پاک شوند؛ برای نگهداری اطلاعات «خیر» را بزنید.

## ساخت فایل انتشار (فقط سازنده)

روی یک سیستم Windows x64، فایل `BUILD_WINDOWS_SETUP.bat` را اجرا کنید. ابزارهای
ساخت در صورت نیاز نصب می‌شوند، تست‌ها اجرا می‌شوند و فایل قابل تحویل در مسیر زیر
قرار می‌گیرد:

```text
installer\output\DailyBook-Setup-x64.exe
```

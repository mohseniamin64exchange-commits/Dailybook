# DailyBook

دفتر روزانه فارسی تحت شبکه داخلی برای ۳ تا ۵ کاربر، با ثبت درآمد و هزینه،
گزارش بدهکار/بستانکار، مدیریت کاربران، Audit Log و پشتیبان‌گیری.

## نصب سریع روی ویندوز

1. فایل `DailyBook-Setup-x64.exe` را اجرا کنید.
2. مراحل نصب را با گزینه‌های پیش‌فرض ادامه دهید.
3. DailyBook از Start Menu یا میانبر Desktop باز می‌شود.
4. در سرور `http://127.0.0.1:4000` و در شبکه
   `http://SERVER-IP:4000` را باز کنید.
5. در اولین اجرا مدیر اصلی را بسازید.

کاربر نهایی به Python، PowerShell، فایل BAT یا اینترنت نیاز ندارد. برنامه در
`C:\Program Files\DailyBook` و اطلاعات آن در `C:\ProgramData\DailyBook` قرار می‌گیرد.

راهنمای کامل در `docs/INSTALL_WINDOWS_FA.md` قرار دارد.

## قابلیت‌ها

- رابط فارسی RTL، تاریخ شمسی و اعداد فارسی
- قفل حساب پس از ۵ رمز اشتباه
- ثبت، ویرایش و حذف نرم درآمد/هزینه با کنترل مالکیت
- دفتر روزانه کلاسیک و چاپ A4/A5
- Audit Log با snapshot و before/after
- بکاپ دستی و روزانه، fallback و اعتبارسنجی SQLite
- SQLite با WAL و busy timeout برای شبکه کوچک
- پورت پیش‌فرض ۴۰۰۰ با امکان تغییر از صفحه تنظیمات مدیر

در نسخه نصب‌شده، تغییر پورت از پنل مدیر قانون فایروال را به‌روزرسانی و سرویس
DailyBook را خودکار Restart می‌کند.

## ساخت Setup برای انتشار

این مرحله فقط یک‌بار توسط سازنده روی Windows x64 انجام می‌شود. فایل
`BUILD_WINDOWS_SETUP.bat` را با دوبار کلیک اجرا کنید. پس از تست و بسته‌بندی، فایل
نهایی در `installer\output\DailyBook-Setup-x64.exe` ساخته می‌شود.

## تست توسعه

```text
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\pytest -q
```

فایل SQLite را روی Share شبکه باز نکنید؛ فقط برنامه سرور باید به آن دسترسی داشته
باشد. برنامه برای انتشار مستقیم روی اینترنت طراحی نشده است.
